# توابع به عنوان Object در پایتون (Functions as Objects)

---

# مقدمه

یکی از قوی‌ترین قابلیت‌های پایتون این است که **تابع (Function) خودش یک Object است.**

یعنی همان‌طور که می‌توانیم عدد، رشته یا لیست را داخل یک متغیر قرار دهیم، می‌توانیم **خود تابع** را نیز داخل متغیر، لیست یا دیکشنری ذخیره کنیم.

این مفهوم پایه بسیاری از فریمورک‌های حرفه‌ای پایتون مانند Django، FastAPI، Flask و حتی سیستم منوهایی است که در پروژه User Manager ساختیم.

---

# مرحله ۱ — اجرای معمولی تابع

ابتدا یک تابع ساده می‌سازیم.

```python
def hello():
    print("Hello")
```

اجرای تابع:

```python
hello()
```

خروجی:

```
Hello
```

در این حالت از پرانتز `()` استفاده کردیم، بنابراین تابع اجرا شد.

---

# مرحله ۲ — خود تابع را داخل متغیر قرار دهیم

```python
def hello():
    print("Hello")

x = hello
```

دقت کن:

اینجا ننوشته‌ایم:

```python
hello()
```

بلکه نوشته‌ایم:

```python
hello
```

یعنی خود تابع را داخل متغیر `x` ذخیره کرده‌ایم.

در این لحظه هیچ چیزی چاپ نمی‌شود.

---

اگر بنویسیم:

```python
print(x)
```

خروجی چیزی شبیه این خواهد بود:

```
<function hello at 0x000001...>
```

یعنی متغیر `x` اکنون یک تابع را در خود نگه داشته است.

---

# اجرای تابع از طریق متغیر

اکنون می‌توانیم بنویسیم:

```python
x()
```

خروجی:

```
Hello
```

چرا؟

زیرا:

```
x == hello
```

در واقع این کد اجرا می‌شود:

```python
hello()
```

---

# نتیجه مهم

تابع نیز مانند سایر داده‌ها یک Object است.

همان‌طور که می‌توانیم بنویسیم:

```python
number = 10

name = "Hossein"

items = []
```

می‌توانیم بنویسیم:

```python
action = hello
```

---

# مرحله ۳ — انتخاب تابع در زمان اجرا

دو تابع می‌سازیم.

```python
def hello():
    print("Hello")


def bye():
    print("Bye")
```

اکنون:

```python
action = hello
```

و سپس:

```python
action()
```

خروجی:

```
Hello
```

اگر مقدار متغیر را تغییر دهیم:

```python
action = bye
```

و دوباره اجرا کنیم:

```python
action()
```

خروجی:

```
Bye
```

---

# چرا این قابلیت مهم است؟

زیرا برنامه می‌تواند در زمان اجرا تصمیم بگیرد که کدام تابع اجرا شود.

این دقیقاً همان چیزی است که در پروژه User Manager اتفاق می‌افتد.

---

# مرحله ۴ — ذخیره تابع داخل لیست

```python
items = [
    hello,
    bye
]
```

لیست اکنون شامل دو تابع است.

```
items

├── hello
└── bye
```

اگر بنویسیم:

```python
items[0]()
```

در واقع این اجرا می‌شود:

```python
hello()
```

و اگر بنویسیم:

```python
items[1]()
```

در واقع این اجرا می‌شود:

```python
bye()
```

---

# مرحله ۵ — ذخیره تابع داخل Dictionary

اکنون به جای لیست، از دیکشنری استفاده می‌کنیم.

```python
menu = {
    "title": "Hello",
    "action": hello
}
```

دقت کن:

اشتباه:

```python
"action": hello()
```

درست:

```python
"action": hello
```

زیرا می‌خواهیم خود تابع ذخیره شود، نه اینکه همان لحظه اجرا شود.

---

اگر بنویسیم:

```python
print(menu["action"])
```

خروجی:

```
<function hello ...>
```

اگر بنویسیم:

```python
menu["action"]()
```

در واقع این اجرا می‌شود:

```python
hello()
```

---

# مرحله ۶ — پروژه User Manager

در پروژه ما:

```python
user_menu_items = [
    {
        "title": "Profile",
        "action": show_profile
    },
    {
        "title": "Change Password",
        "action": change_password
    },
    {
        "title": "Logout",
        "action": logout
    }
]
```

فرض کنیم کاربر گزینه سوم را انتخاب کرده است.

```
choice = 2
```

اکنون:

```python
user_menu_items[2]
```

برابر است با:

```python
{
    "title": "Logout",
    "action": logout
}
```

اگر بنویسیم:

```python
user_menu_items[2]["action"]
```

خروجی:

```
logout
```

نه:

```
logout()
```

هنوز تابع اجرا نشده است.

---

اکنون:

```python
user_menu_items[2]["action"]()
```

در واقع تبدیل می‌شود به:

```python
logout()
```

---

# اگر تابع پارامتر داشته باشد

فرض کنیم:

```python
def logout(current_user):
    print(current_user["name"])
```

اکنون:

```python
user_menu_items[2]["action"](current_user)
```

در واقع این است:

```python
logout(current_user)
```

هیچ تفاوتی وجود ندارد.

فقط تابع را از داخل دیکشنری گرفته‌ایم.

---

# تجزیه یکی از مهم‌ترین خطوط پروژه

```python
result = user_menu_items[choice]["action"](current_user)
```

این خط را مرحله به مرحله بخوان.

---

## مرحله اول

```python
user_menu_items[choice]
```

نتیجه:

```python
{
    "title": "...",
    "action": ...
}
```

---

## مرحله دوم

```python
["action"]
```

نتیجه:

```python
show_profile
```

---

## مرحله سوم

```python
(current_user)
```

نتیجه:

```python
show_profile(current_user)
```

---

# این خط دقیقاً معادل چیست؟

به جای نوشتن:

```python
if choice == 0:
    show_profile(current_user)

elif choice == 1:
    change_password(current_user)

elif choice == 2:
    logout(current_user)
```

فقط کافی است بنویسیم:

```python
user_menu_items[choice]["action"](current_user)
```

و پایتون خودش تابع مناسب را اجرا می‌کند.

---

# مزایای این روش

* کد بسیار کوتاه‌تر می‌شود.
* نیازی به تعداد زیادی if و elif نداریم.
* اضافه کردن گزینه جدید بسیار ساده است.
* کد تمیزتر و حرفه‌ای‌تر می‌شود.
* ساختار پروژه راحت‌تر توسعه پیدا می‌کند.

---

# اشتباه رایج

اشتباه:

```python
"action": logout()
```

در این حالت تابع همان لحظه اجرا می‌شود و مقدار برگشتی آن داخل دیکشنری ذخیره می‌شود.

---

درست:

```python
"action": logout
```

در این حالت خود تابع ذخیره می‌شود و هر زمان که لازم بود اجرا خواهد شد.

---

# نکات مهم

✅ تابع نیز یک Object است.

✅ می‌توان تابع را داخل متغیر ذخیره کرد.

✅ می‌توان تابع را داخل لیست ذخیره کرد.

✅ می‌توان تابع را داخل دیکشنری ذخیره کرد.

✅ با استفاده از `()` تابع اجرا می‌شود.

✅ بدون `()` فقط به خود تابع اشاره می‌کنیم.

---

# خلاصه درس

امروز یاد گرفتیم که در پایتون، تابع نیز مانند عدد، رشته یا لیست یک Object است.

به همین دلیل می‌توان آن را داخل متغیر، لیست یا دیکشنری قرار داد و هر زمان که لازم بود اجرا کرد.

همین مفهوم ساده، پایه طراحی سیستم منو در پروژه User Manager است و در بسیاری از فریمورک‌های حرفه‌ای پایتون نیز دقیقاً از همین ایده استفاده می‌شود.
